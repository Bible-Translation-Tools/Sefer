# Roadmap

From the sefer-next-features doc's status of 2026-10-13, and the items as they stand
(2026-10-14). Steps run in rough order within a phase.

Sefer aims to be the organisation's best tool for reading and writing Bible-domain text, starting
with scripture revision. Not a study tool like Logos or Accordance; publishing stays separate.

- **Revision first; drafting later.** Drafting is revision from zero; the gap is adding a new book.
- **Beyond USFM, if wanted:** discussion, a Markdown glossary with its passages, notes. The primitives that carry it are book–chapter–verse addressing, versification and alignment.
- **Move fast.** The data is not personal, and Sefer works fully offline: the bar is less tool friction and fewer handoffs.
- **USFM as a string.** Offsets make find, alignment, diffs and the editor work; other formats are converted in, not edited as trees.
- **AI explains; it does not translate.** The same typed tools serve tours, workflows, discussion cells and model tool calls.
- **Word-aligned USFM is not an editing target.** Translate first, then align in a dedicated interface; IBM Model 2 can get part of the way.
