A workflow joins state Sefer already holds to UI, driven in a set order. It is not an editor
feature but a driver that points the reader's attention somewhere, so it can be reached from a
command, a URL, a tour or an LLM tool.

**Built** (the Oct 12–13 stack): the step machine shared by tours and workflows, Triage verse
numbers, `?workflow=` and Settings' Workflows tab, share links (`/r/<owner>/<repo>/<place>`), and
`data-tour` handles. How they work: `documentation/architecture/shell.md`, "Tutorials and workflows".
