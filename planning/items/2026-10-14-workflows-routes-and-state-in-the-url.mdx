A workflow joins state Sefer already holds to UI, driven in a set order. It is not an editor
feature but a driver that points the reader's attention somewhere, so it can be reached from a
command, a URL, a tour or an LLM tool.

## Built (on the stack)

- **The step machine**, shared by tours and workflows: go, ready, then a spotlight or a docked panel; fails open while the UI moves (`src/app/tour/`).
- **Triage verse numbers**, the first workflow, with Renumber from `Finding.expected`; `?workflow=<id>` starts one; Settings has a Workflows tab.
- **Share links** as `/r/<owner>/<repo>/<place>?at=&host=`, rather than the sketched `/{owner}/{repo}`; a link names its cloud.
- **Tour handles** are a `data-tour` attribute; the rest of the app does not know tours exist.
