From the Oct 7 memo: the editor works but has rough edges from the revision push, and its cursor
code is the gnarliest in the app (binary searches, high cyclomatic complexity).

<Followup id="headline-rule">State the headline rule at the top of `documentation/architecture/editor.md`: **a CodeMirror line is not a USFM line.** Newlines are drawn by context (a joined newline is a space), so never split on doc lines or use `doc.line` as a unit. (Added Oct 8; check it is committed.)</Followup>

<Followup id="cursor">Refine cursor mechanics on the playground with the arrow keys. Cursor code is a first target for the [fallow pass](/items/2026-10-14-fallow-readability-pass).</Followup>

<Followup id="tests">Put tests back around copy, paste and Enter.</Followup>

<Followup id="formatter">Revisit the USFM formatter, written before the editor drew newlines by context. Consider format-on-save.</Followup>
