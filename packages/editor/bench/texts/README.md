# Bench texts

One chapter each, sliced from whole books for the bench's side-by-side scenarios:

- `*-ulb.usfm`: the _Unlocked Literal Bible_ (en_ulb), © Wycliffe Associates, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Kept as published, `\s5` chunk markers included.
- `*-bsb.usfm`: the _Berean Standard Bible_, public domain since 2023.

The book header is kept so each slice is a valid book; nothing else is changed.
